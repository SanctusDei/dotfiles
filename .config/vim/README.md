# VimKeys · Master Vim 快捷操作

普通模式按 ;? 或输入 :VimKeys 打开。此页只读，按 q 返回代码。
输入 :VimKeys 补全、:VimKeys Python 等可直达对应章节，命令后支持 Tab 选择主题。
页内用 /关键词 搜索，n / N 查找下一处 / 上一处，gg / G 到顶部 / 底部。

; 是前导键，先按分号，再按后面的键；大小写不同。Ctrl-x Ctrl-o 表示依次按两个组合键。
未注明的快捷键在普通模式使用；先按 Esc 可返回普通模式。

## 快速开始

| 目的 | 操作 |
| --- | --- |
| 开始输入 / 返回普通模式 | i / Esc |
| 保存 / 保存退出 / 不保存退出 | ;w / :wq / :q! |
| 找文件 / 找项目中的内容 | Ctrl-p / ;/ 后输入搜索词并回车 |
| 文件树 / 代码结构 | F3 / F9 |
| 运行 / 格式化 | F5 / F6 |
| 主动补全 / 确认候选 | 插入模式 Tab / Enter |
| 查看错误详情 / 下一个问题 | ;k / ;n |
| 查看 Python 环境 / 检查配置 | :PythonInfo / :VimHealth |
| 打开本页 / 关闭本页 | ;? 或 :VimKeys / q |

## 补全与输入

适用于 Python、C、C++。代码补全来自 Jedi / clangd；字符串另有文本和路径候选。

| 插入模式按键 | 行为 |
| --- | --- |
| 正常输入后稍作停顿 | 自动弹出代码候选 |
| Tab（没有菜单） | 代码文字后主动请求补全；字符串内请求上下文、文本与路径候选 |
| Tab / Shift-Tab（已有菜单） | 下一项 / 上一项 |
| Enter（已有菜单） | 确认当前候选，不换行；未选候选时确认第一项 |
| Enter（没有菜单） | 正常换行，保留括号内缩进 |
| Ctrl-e（已有菜单） | 取消补全菜单，保留原输入 |
| Ctrl-x Ctrl-o | 主动请求语言服务补全 |
| Ctrl-Space | 同上；终端可能占用这个组合键，可改用 Tab |
| Tab（行首或空白后） | 插入缩进 |
| Shift-Tab（没有菜单） | 减少一级缩进 |

字符串输入至少两个文字字符后，语言服务没有候选时会补充已打开文件中的匹配单词。
例如已有 hello_world，输入 "hel" 可得到该候选；"./data/re" 可匹配 report.csv。
路径相对于当前源文件目录。候选来自实际内容，不会生成任意句子。
括号和引号自动配对；输入已有的闭括号或引号可跳过它。

## 文件搜索与目录

| 普通模式按键 | 功能 |
| --- | --- |
| Ctrl-p | 模糊搜索当前工作目录下的文件 |
| ;/ 然后输入关键词并回车 | 全文搜索当前工作目录（ripgrep） |
| ;b | 搜索已打开的缓冲区 |
| F3 | 开关 NERDTree 文件树；插入模式也可用 |
| ;e | 在文件树中定位当前文件 |
| F9 | 开关 Tagbar 代码结构侧栏 |
| /关键词，然后 n / N | 当前文件中搜索、跳到下一处 / 上一处 |
| Esc | 普通模式清除搜索高亮 |

建议先在终端 cd 到项目根目录再启动 Vim。打开文件不会自动改变工作目录。
可用 :pwd 查看目录，:cd 路径 切换目录。
搜索包含隐藏文件，排除 .git、node_modules、.venv、__pycache__。
在文件树中 Enter 打开文件，q 关闭侧栏。

## 窗口缓冲区与标签页

| 按键 | 功能 |
| --- | --- |
| ;v / ;s | 左右分屏 / 上下分屏 |
| Ctrl-w h / j / k / l | 切换到左 / 下 / 上 / 右窗口 |
| Ctrl-w w | 轮流切换窗口 |
| Ctrl-w = | 均分窗口大小 |
| Ctrl-w c | 关闭当前窗口 |
| ;bn / ;bp | 下一个 / 上一个缓冲区 |

缓冲区是已打开的文件，窗口是显示文件的区域，标签页可以包含多个窗口。
切换文件不会强制丢弃修改；用 :ls 查看全部缓冲区，:b 编号 切换。

## Tagbar 代码结构

F9 打开右侧代码结构列表，并自动把焦点移入侧栏。它列出当前文件的函数、类、方法、变量等符号。

常用流程：F9 → j / k 找到函数 → Enter 跳转到定义并回到代码。
符号很多时可在侧栏用 /名称 搜索，按 n 查找下一项。

| Tagbar 侧栏按键 | 功能 |
| --- | --- |
| j / k | 向下 / 向上移动 |
| Enter / 鼠标双击 | 跳到符号定义；分类标题上按 Enter 可切换折叠 |
| p | 在源码窗口定位符号，焦点留在侧栏 |
| P | 在预览窗口显示符号 |
| 空格 | 在命令区显示符号原型 |
| + / - | 展开 / 折叠当前分组 |
| o | 切换当前分组折叠 |
| * / = | 展开全部 / 折叠全部 |
| s | 在名称排序与文件顺序之间切换 |
| Ctrl-n / Ctrl-p | 下一个 / 上一个顶层符号 |
| ? / F1 | 查看 Tagbar 自带帮助 |
| q / F9 | 关闭侧栏 |

Ctrl-w h / l 可以在源码与右侧侧栏之间切换。
若列表为空，先确认文件已设置正确类型（:set filetype?）；用 :VimHealth 检查 ctags。
完整插件说明：:help tagbar。

## 运行调试与终端

| 普通模式按键 / 命令 | 功能 |
| --- | --- |
| F5 / :Run | 保存当前源文件，在下方终端编译或运行 |
| F8 / :Run! | 编译 C/C++ 并启动 gdb |
| 终端输入模式下 Esc Esc | 返回终端普通模式，再用 Ctrl-w 切换窗口 |
| 终端普通模式下 i | 重新进入终端输入模式 |
| 终端中的 Ctrl-c | 中断当前运行程序 |

F5 支持 C、C++、Python、shell、Go、Java；缺少相应工具时会提示。
C/C++ 使用 gcc / g++，编译失败不会执行旧产物；输出程序放在 Vim 的状态目录。
F5 面向单文件练习；多文件工程使用项目自身的 Make / CMake 等构建命令。
F8 进入 gdb 后，可用 break main、run、next、print 变量、quit。

## 诊断格式化与代码导航

| 普通模式按键 | 功能 |
| --- | --- |
| ;l | 主动检查当前文件 |
| ;k | 查看光标处错误或警告详情 |
| ;n / ;p | 下一处 / 上一处诊断，末尾会循环 |
| ;d | 跳转定义（Python / C / C++） |
| ;r | 查找引用（Python / C / C++） |
| Ctrl-o / Ctrl-i | 原生跳转列表中后退 / 前进 |
| F6 / ;f | Python 用 Ruff 格式化，C/C++ 用 clang-format，其他类型使用 Vim 缩进 |
| F12 | 全文使用 Vim 缩进，并恢复光标位置 |

打开文件、离开插入模式和保存时执行检查；保存时不自动格式化。
左侧 ✗ 是错误，! 是警告。自动消息和文字下划线已关闭，用 ;k 查看详情。
格式化结果先更新缓冲区，按 ;w 保存。:lopen 打开诊断列表，:lclose 关闭。
Ruff 和 clang-format 会读取项目自己的格式配置（若存在）。

## Python 环境

:PythonInfo 显示当前文件实际使用的解释器，比终端提示符或 PATH 更准确。
F5 执行与 Jedi 分析共用以下选择顺序：

1. 当前缓冲区显式指定的 b:master_python。
2. 已激活的 VIRTUAL_ENV，然后是 CONDA_PREFIX。
3. 源文件目录向上最近的 .venv / venv，遇到 Git 根目录停止继续向上查找。
4. PATH 中的 python3，其次 python。

因此，项目已有 uv venv 创建的 .venv 时，直接打开项目文件即可自动识别，无需手动激活。
Jedi 服务本身独立安装；其分析目标仍是项目解释器。Ruff 是独立的检查和格式化工具。
切换环境后重新启动 Vim，让已启动的语言服务重新连接。

临时为当前文件指定解释器：

```vim
:let b:master_python = '/绝对路径/.venv/bin/python3'
:PythonInfo
```

取消指定：:unlet b:master_python。临时修改后执行 :ALEStopAllLSPs，再执行 :ALELint，让服务按新设置连接；这会重连所有语言服务。缓冲区变量不会在退出 Vim 后保留。
终端直接运行项目代码时，可用 uv run python 文件.py；这与 Vim 的自动环境选择分开。

## 注释剪贴板与基础编辑

| 按键 | 功能 |
| --- | --- |
| gcc | 注释 / 取消注释当前行 |
| gc 加动作，例如 gcap | 注释 / 取消注释指定范围，例如段落 |
| 可视模式选中后 gc | 注释 / 取消注释选区 |
| v / V / Ctrl-v | 字符 / 整行 / 矩形选择 |
| yy / p | 复制整行 / 粘贴 Vim 寄存器 |
| ;yy | 复制整行到系统剪贴板 |
| ;Y / :Copy | 复制全文到系统剪贴板（大写 Y） |
| 可视模式选中后 Ctrl-c | 复制选区到系统剪贴板 |
| ;yiw | 复制当前单词到系统剪贴板 |
| 可视模式选中后 ;y | 复制选区到系统剪贴板 |
| ;P | 从系统剪贴板粘贴（大写 P） |
| u / Ctrl-r | 撤销 / 重做 |
| >> / << | 增加 / 减少当前行缩进 |

复制在 WSL 下自动调用 Windows 剪贴板，支持中文、多行和矩形选区；内容也保留在 Vim 中，可用 p 粘贴。
普通模式 ;y 后接动作，如 ;yy 整行、;yiw 单词；可视模式 Ctrl-c / ;y 复制选区。
:3,8Copy 复制第 3 到 8 行。;P 仍使用 Vim 原生系统剪贴板粘贴，需要可用的桌面剪贴板连接。
yy / p 始终可在 Vim 内部复制、粘贴，不依赖系统剪贴板。
普通模式 Ctrl-p 是找文件；插入模式 Ctrl-p 是 Vim 原生补全上一项。

## Git

;g 打开 Fugitive Git 状态窗口。项目必须位于 Git 仓库中。
状态窗口里按 - 暂存 / 取消暂存光标处文件，cc 创建提交，= 查看差异，q 关闭。
常用命令：:Git diff、:Git log、:Git blame。
暂存与提交会修改仓库状态，请在查看差异后操作。

## 恢复与保存

| 提示 / 操作 | 含义 |
| --- | --- |
| ;w / :w | 保存当前文件；;w 只在内容修改时写盘 |
| :wa | 保存所有已修改文件 |
| :wq / :q / :q! | 保存退出 / 退出 / 不保存退出 |
| 恢复菜单 R 或回车 | 恢复已结束会话中的内容 |
| 恢复菜单 O | 只读打开 |
| 恢复菜单 Q 或 Esc | 取消 |

若原进程仍运行或状态不明，恢复菜单只提供“只读 / 取消”，默认取消。
恢复后先检查内容，再保存。保存成功后，符合条件的旧交换文件会自动归档。
持久撤销、swap、备份、运行产物统一保存在 ~/.local/state/vim/，不散落到项目中。
归档的恢复记录位于 ~/.local/state/vim/recovery/。

## 自检与常见问题

| 命令 / 情况 | 操作 |
| --- | --- |
| :VimHealth | 检查工具路径、插件目录、恢复设置 |
| :PythonInfo | 查看当前 Python 运行与分析环境 |
| :ALEInfo | 查看当前文件实际启用的检查器及运行记录 |
| :messages | 查看最近的 Vim 消息 |
| 补全突然失效 | 确认 :set paste? 显示 nopaste；必要时执行 :set nopaste |
| 模块找不到 | 用 :PythonInfo 核对环境，再在该项目环境中安装依赖 |
| Ctrl-Space 不触发 | 改用 Tab 或 Ctrl-x Ctrl-o，避免终端快捷键冲突 |
| F5 缺少工具 | 按提示安装该语言的编译器或解释器 |

编辑区同时启用绝对行号与相对行号：当前行显示实际行号，其他行显示相对距离；终端缓冲区不显示行号。
关闭了声音和视觉铃声；行号不会随插入模式切换。
修改插件启动设置后完全退出并重新打开 Vim。

界面使用 Tokyo Night Moon 风格的实色深蓝灰背景，状态栏与侧栏保持同一配色。
NERDTree / 代码 / Tagbar 的目标宽度约为 18% / 63% / 19%；侧栏打开或终端缩放后自动调整，窄屏优先保留代码空间。
当前编辑窗口显示柔和的当前行高亮，其他编辑窗口背景略暗。
终端透明度由终端模拟器自行设置，建议约 95% 不透明度；Vim 配置不会修改它。

## 配置与插件维护

配置入口：~/.vimrc。主题、辅助函数与本说明：~/.config/vim/。
统一使用 vim-plug，:PlugStatus 查看状态，:PlugUpdate 手动更新。
旧 ~/.vim/plugin、ftplugin、after 已停用，原文件保留。
插件复用 ~/.vim/plugged/，Fugitive 复用 ~/.vim/bundle/vim-fugitive/。
不要执行 :PlugClean 清理未启用的旧仓库，它们仍用于旧配置回退。

配置备份位于 ~/.config/vim-backups/。需要回退时，先选定备份：
- 将对应 vimrc 复制回 ~/.vimrc。
- 将对应 runtime/ 恢复到 ~/.config/vim/（若该备份包含 runtime）。
- 完全退出并重新打开 Vim。
